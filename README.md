# Novel Planning Toolkit

A set of nine markdown templates for planning a novel — from the one-page overview down to how subplots weave together. Each file is meant to be copied and filled in per project (or edited in place if you're only working on one book at a time).

## Templates

1. [Overview](01_Overview.md) — the one-page snapshot: premise, conflict, stakes, themes, tone, and a full synopsis.
2. [Setting](02_Setting.md) — world basics, locations, world rules, culture & society.
3. [Main Characters](03_Main_Characters.md) — full-depth profiles for your protagonist and any co-leads.
4. [Secondary Characters](04_Secondary_Characters.md) — moderate-depth cards for allies, rivals, mentors, love interests.
5. [Minor Characters](05_Minor_Characters.md) — a running cast list for continuity.
6. [Plot Archetypes](06_Plot_Archetypes.md) — the seven basic plots, plus fields to name your own.
7. [Plot Endings](07_Plot_Endings.md) — common ending types, plus a thread-resolution table.
8. [Disconnected Plots](08_Disconnected_Plots.md) — a parking lot for ideas that don't connect yet.
9. [Writing & Connecting Plots](09_Writing_Connecting_Plots.md) — the subplot tracker and chapter-by-chapter thread map.

## Suggested order

Start with **Overview** and **Setting** to fix the big picture, then build out **Main**, **Secondary**, and **Minor Characters**. Use **Plot Archetypes** and **Plot Endings** to shape the structure, log any stray ideas in **Disconnected Plots**, and finish in **Writing & Connecting Plots** once you're ready to weave everything into a chapter-by-chapter plan.

## How to use these files

Each template uses standard Markdown headings, tables, and blank fields. Fill them in directly in any text editor, or duplicate a file (e.g. copy `04_Secondary_Characters.md` to `04_Secondary_Characters_Aldric.md`) if a project needs more entries than the template provides space for.
